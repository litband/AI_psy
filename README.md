# AI Psy — тест акцентуаций характера

Веб-тест акцентуаций характера по опроснику Леонгарда–Шмишека (88 вопросов). Чистый JavaScript на нативных ES-модулях: без сборки и без внешних зависимостей.

Демо: https://litband.github.io/AI_psy/

**Важно:** тест не является диагнозом и не заменяет консультацию специалиста.

## Запуск локально

ES-модули не работают через `file://`, поэтому нужен любой статический сервер, например:

```bash
cd D:\projects\AI_psy
python -m http.server 8000
```

и откройте http://localhost:8000.

Тесты: откройте `tests/test.html` через тот же сервер (http://localhost:8000/tests/test.html).

## Структура

- `src/data/` — опросники (`schmieschek.js`) и описания типов (`types.js`)
- `src/core/` — подсчёт баллов (`scoring.js`), хранилище (`storage.js`), передача ответов по ссылке (`share.js`)
- `src/ui/` — экраны (`screens/`) и график (`chart.js`)
- `src/app.js` — hash-роутер
- `css/` — стили (`base.css`, `components.css`, `print.css`)
- `tests/` — тесты в браузере
- `doc/` — документация и контракты модулей; подробнее: `doc/Контекст/README.md`

## Данные

Результаты хранятся только в браузере пользователя (localStorage) и не отправляются на сервер.
