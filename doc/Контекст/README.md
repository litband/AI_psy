# AI_psy — контекст проекта (читать первым в новом чате)

**Что это:** веб-приложение — психологический тест на акцентуации характера по классификации К. Леонгарда (развита А. Личко). MVP — опросник Леонгарда–Шмишека (88 вопросов да/нет, 10 шкал).

**Репозиторий:** https://github.com/litband/AI_psy (public), ветка `main`.
**Хостинг:** GitHub Pages — https://litband.github.io/AI_psy/
